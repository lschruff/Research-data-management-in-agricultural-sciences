# Research Data Management in Agricultural Sciences - Advanced module: Data documentation – Trainingsmaterial

## Content

As part of the series ‘Tailored Research Data Management Training for Agricultural Scientists’ in cooperation between FAIRagro, the Consortium for the Agrosystems Research Community of the National Research Data Infrastructure (NFDI) and the Research Data Service of the University of Kassel, an in-depth workshop on Data documentation was held at 10th of December 2024, which specifically addressed the special features for agricultural scientists. This publication is intended to enable the subsequent use of the teaching materials and includes this README file, which also functions as a navigation aid for the individual files. The Teachingscript (in German only), helps with the conception, division of labour and timing of the introductory lecture. This and the presentation slides are available in various formats for easy reuse.

- **Target group of the workshop:** Researchers, focus on young scientists
- **Competence level:** Basic level, Intermediate level
- **Domain:** Agricultural sciences
- **Duration:** 2 h
- **Learning resource type:** Presentation slides, teaching script
- **Formats:** pdf, pptx, odp, xlsx, ods
